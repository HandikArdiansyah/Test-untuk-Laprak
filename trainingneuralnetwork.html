3. Pertanyaan Besar

"Forward propagation hanya menghitung. Tapi bagaimana network tahu weight-nya salah?"

Analogi: Melempar Panah

Bayangkan Anda melempar panah ke papan target.

  • Lemparan 1 → meleset jauh ke kiri
  • Anda lihat seberapa jauh dari pusat
  • Anda koreksi arah lemparan berikutnya
  • Lemparan 2 → lebih dekat

Network belajar dengan cara yang sama:

  1. Buat prediksi
  2. Ukur seberapa jauh dari target → loss
  3. Cari tahu weight mana yang harus diubah → backpropagation
  4. Ubah sedikit → update weight

Tiga Pertanyaan Kunci

  1. Seberapa salah?
    → Loss function
  2. Ke arah mana harus bergerak?
    → Gradient descent
  3. Weight mana yang paling bersalah?
    → Backpropagation

4. Loss Function — "Seberapa Salah Prediksi Saya?"

Loss adalah satu angka yang merangkum: seberapa jauh prediksi dari jawaban benar.

Untuk klasifikasi biner (ban: Baik vs Perlu Perbaikan), kita pakai Binary Cross-Entropy (BCE):

L = −[ y · log(ŷ) + (1 − y) · log(1 − ŷ) ]
Bacaan visual rumus ini:
  • Jika target y = 1 dan prediksi ŷ = 0.99 → loss ≈ 0.01 (hampir sempurna)
  • Jika target y = 1 dan prediksi ŷ = 0.10 → loss ≈ 2.30 (sangat salah)
  • Loss menghukum prediksi yang percaya diri tapi salah jauh lebih berat
Aturan praktis output layer:
Klasifikasi biner → output Sigmoid + loss BCE
Regresi → output Linear + loss MSE

5. Gradient Descent — "Ke Arah Mana Saya Harus Bergerak?"

Bayangkan loss sebagai lembah. Kita ingin sampai ke dasar lembah (loss = 0).

Update weight mengikuti aturan sederhana:

w ← w − η · ∂L/∂w

η (eta) = learning rate — seberapa besar langkah yang diambil

Pengaruh Learning Rate

η terlalu kecil

Langkah mungil. Butuh ribuan epoch. Konvergen, tapi lambat.

Seperti menuruni gunung dengan langkah 5 cm.

η pas

Turun mulus dan cepat. Ini yang kita inginkan.

Seperti menuruni gunung dengan langkah wajar.

η terlalu besar

Melompati lembah, bahkan mental ke atas. Loss tidak turun.

Seperti melompat dari tebing ke tebing.
Catatan: learning rate yang umum dipakai untuk Adam di contoh kecil: 0.01. Nilai ini bukan harga mati — selalu tuning.

6. Backpropagation — "Weight Mana yang Paling Bersalah?"

Loss memberi tahu kita seberapa salah. Tapi weight mana yang harus diubah? Di sinilah backpropagation: error mengalir mundur dari output ke input, melewati setiap weight.

Panah besar = gradient besar = weight ini paling berpengaruh terhadap loss.

Analogi Visual

Bayangkan loss sebagai "nilai kesalahan" di ujung output. Backpropagation menanyakan ke tiap neuron:

"Kalau kamu mengubah outputmu sedikit, seberapa besar loss berubah?"

Jawaban itu = gradient. Semakin besar, semakin perlu diubah.
Yang perlu diingat mahasiswa (tanpa kalkulus):
  • Backpropagation = error mengalir mundur lewat chain rule
  • Di hidden layer dengan ReLU, gradient mengalir utuh (×1) untuk x > 0
  • Di hidden layer dengan Sigmoid, gradient menipis setiap layer (×0.25 atau lebih kecil)

7. Kenapa ReLU? — Bukti Visual

Di pertemuan lalu kita percaya pada rule of thumb "hidden layer → ReLU". Sekarang kita buktikan.

7.1 Masalah Sigmoid di Hidden Layer

Bayangkan 3 layer Sigmoid bertumpuk. Setiap kali error mundur melewati satu Sigmoid, gradient-nya dikalikan dengan nilai ≤ 0.25.

Layer Output
gradient = 1.00
Hidden 3
gradient = 0.25
Hidden 2
gradient = 0.06
Hidden 1
gradient = 0.015

Sinyal error yang sampai ke layer awal hampir nihil. Layer awal nyaris tidak belajar.

Ini disebut vanishing gradient.
Semakin dalam network, semakin parah. Inilah alasan historis mengapa deep network sulit dilatih sebelum ReLU populer.

7.2 ReLU Menjaga Sinyal

ReLU(x) = max(0, x). Untuk x > 0, gradient-nya = 1. Error bisa lewat tanpa melemah.

Layer Output
gradient = 1.00
Hidden 3 (ReLU)
gradient = 1.00
Hidden 2 (ReLU)
gradient = 1.00
Hidden 1 (ReLU)
gradient = 1.00

Error mengalir utuh sampai layer paling awal. Semua layer ikut belajar.

7.3 Perbandingan Fungsi & Gradient

ActivationBentukGradient di hiddenCocok untuk
Sigmoid Kurva S, output 0–1 ≤ 0.25 → menipis Output biner
Tanh Kurva S, output −1–1 ≤ 1.0 → tetap menipis Jarang, kadang di RNN
ReLU Garis lurus untuk x>0, 0 untuk x<0 1 atau 0 → utuh Hidden layer
Analogi sederhana:
Sigmoid seperti guru yang menjelaskan makin pelan setiap kali turun kelas — sampai akhirnya berhenti bicara. ReLU seperti guru yang langsung bilang "lanjut" selama ada yang perlu dijelaskan, dan baru diam kalau memang tidak ada.

8. Praktik PyTorch — 3 Eksperimen

Kita pakai studi kasus pabrik ban: klasifikasi Baik / Perlu Perbaikan dari 4 parameter proses.

Dataset & Persiapan

import torch import torch.nn as nn import matplotlib.pyplot as plt torch.manual_seed(42) # ====== Dataset sintetis: 200 ban ====== # Fitur: suhu, tekanan, waktu curing, rasio karet n = 200 X = torch.rand(n, 4) # normalisasi kasar agar mirip parameter nyata X[:, 0] = X[:, 0] * 40 + 140 # suhu 140-180 X[:, 1] = X[:, 1] * 10 + 15 # tekanan 15-25 X[:, 2] = X[:, 2] * 7 + 8 # waktu 8-15 X[:, 3] = X[:, 3] * 0.4 + 0.4 # rasio 0.4-0.8 # Aturan non-linear: ban baik jika suhu di rentang "ideal" (150-165) # dan tekanan cukup. Di luar itu cenderung perlu perbaikan. suhu_ideal = ((X[:, 0] > 150) & (X[:, 0] < 165)).float() tekanan_ok = (X[:, 1] > 19).float() y = ((suhu_ideal * 0.7 + tekanan_ok * 0.3) > 0.6).float().unsqueeze(1) # Normalisasi fitur (penting untuk training stabil) X = (X - X.mean(0)) / X.std(0)

Arsitektur & Fungsi Training

def build_model(hidden_activation): return nn.Sequential( nn.Linear(4, 8), hidden_activation, nn.Linear(8, 8), hidden_activation, nn.Linear(8, 1), nn.Sigmoid() # output tetap Sigmoid ) def train(hidden_activation, epochs=300, lr=0.01): torch.manual_seed(42) model = build_model(hidden_activation) loss_fn = nn.BCELoss() optimizer = torch.optim.Adam(model.parameters(), lr=lr) losses = [] for epoch in range(epochs): y_pred = model(X) loss = loss_fn(y_pred, y) optimizer.zero_grad() loss.backward() # <-- backpropagation optimizer.step() # <-- update weight losses.append(loss.item()) return losses

Bandingkan 3 Konfigurasi

configs = { "Linear (tanpa activation)": nn.Identity(), "Sigmoid": nn.Sigmoid(), "ReLU": nn.ReLU(), } results = {} for name, act in configs.items(): losses = train(act) results[name] = losses print(f"{name:28s} | Loss akhir: {losses[-1]:.4f}")

Visualisasi Hasil

plt.figure(figsize=(10, 5)) for name, losses in results.items(): plt.plot(losses, label=name, linewidth=2) plt.xlabel("Epoch") plt.ylabel("Loss") plt.title("Perbandingan Activation Function di Hidden Layer") plt.legend() plt.grid(True) plt.show()
Pesan utama eksperimen:
Data sama, arsitektur sama, jumlah neuron sama, optimizer sama. Yang berbeda hanya activation function di hidden layer. ReLU membuat loss turun jauh lebih cepat dan lebih dalam. Itulah buktinya.
