3. Hubungkan dengan Neuron yang Sudah Dipelajari

Pada modul sebelumnya, neuron dijelaskan melalui perhitungan:

z = w₁x₁ + w₂x₂ + ... + b

Jika menggunakan sigmoid:

ŷ = σ(z) = 1 / (1 + e⁻ᶻ)

Sekarang pertanyaan kita berubah:

“Kalau hasil ŷ salah, bagaimana w dan b tahu harus berubah ke arah mana?”

Jawabannya adalah loss + gradient/backpropagation + learning rate.

4. Loss: Meteran Kesalahan Model

Loss adalah angka yang membantu kita mengukur seberapa jauh prediksi model dari target.

Loss = ukuran kesalahan antara target (y) dan prediksi (ŷ)

Untuk tahap pengenalan, modul sebelumnya menggunakan contoh MSE:

MSE = (1/n) Σ (y - ŷ)²

Interpretasinya sederhana:

Loss kecil
Prediksi relatif dekat dengan target.
Loss besar
Prediksi masih jauh dari target.

Catatan: pada aplikasi klasifikasi nyata, loss yang digunakan dapat berbeda. Pada pertemuan ini fokusnya adalah memahami mekanisme belajar, bukan menghafal semua jenis loss.

5. Dari “Salah” ke “Perbaikan”

Misalkan target adalah 1 = ban cacat. Model menghasilkan prediksi 0,30.

KomponenNilaiMakna
Target y1Ban memang cacat
Prediksi ŷ0,30Model baru yakin 30%
Error sederhana1 − 0,30 = 0,70Masih cukup jauh

Model tidak “berpikir” seperti manusia. Model menggunakan matematika untuk mengetahui bagaimana perubahan parameter memengaruhi loss.

w_baru = w_lama − learning_rate × gradient
b_baru = b_lama − learning_rate × gradient_bias
Intinya: gradient memberi arah perubahan, sedangkan learning rate menentukan seberapa besar langkah perubahan.

7. Eksperimen #1 — Learning Rate

Learning rate dapat dipahami sebagai ukuran langkah saat model memperbarui parameter.

Learning rate kecil
Perubahan lebih pelan. Banyak iterasi dapat diperlukan.
Learning rate besar
Perubahan lebih besar. Jika terlalu besar, proses optimasi dapat menjadi tidak stabil.
Aktivitas kelas: minta mahasiswa membayangkan sedang mencari titik terendah di lembah. Apakah lebih baik melangkah 1 cm, 1 meter, atau 100 meter?

8. Eksperimen #2 — Epoch

Epoch adalah satu putaran pembelajaran terhadap seluruh data training.

EpochGambaran
1Model baru mulai belajar.
10Model sudah mendapat banyak kesempatan memperbaiki parameter.
100Belum tentu otomatis lebih baik; perlu melihat loss dan validasi.
Jangan ajarkan “semakin banyak epoch pasti semakin bagus”. Yang diamati adalah perubahan performa terhadap data training dan data validasi.

9. Eksperimen #3 — Weight dan Bias

Mahasiswa sudah mengenal weight dan bias dari pertemuan sebelumnya. Sekarang posisinya berubah: weight dan bias adalah parameter yang dipelajari.

Weight

Mengatur kontribusi input terhadap neuron.

Bias

Memberikan pergeseran pada nilai sebelum aktivasi.

Ketika training berlangsung, nilai-nilai ini bukan angka tetap. Optimizer memperbaruinya berdasarkan gradient.

10. Mini Project Industri Ban — “Model Belajar Mendeteksi Ban Cacat”

Contoh ini sengaja dibuat sebagai jembatan menuju praktik CNN pada modul sebelumnya. Jangan langsung meminta mahasiswa membuat CNN besar. Fokus pertemuan 4 adalah memahami proses belajar.

Skenario

Sebuah pabrik ban ingin membantu proses inspeksi kualitas. Setiap ban memiliki label:

LabelArti
0OK / tidak terdeteksi cacat
1NG / terdapat cacat

Versi sederhana untuk memahami konsep

Daripada langsung memakai gambar, gunakan fitur numerik buatan sebagai latihan:

FiturContohInterpretasi
x₁0–1indikator tekstur/permukaan yang sudah dinormalisasi
x₂0–1indikator bentuk/ketidakteraturan yang sudah dinormalisasi
y0 atau 1label OK / NG

Tujuan mahasiswa:

  1. Memberikan data ke neuron.
  2. Menghitung prediksi.
  3. Menghitung loss.
  4. Melihat perubahan weight/bias.
  5. Mengulang training.
  6. Membuat tabel “epoch vs loss”.
  7. Menjelaskan mengapa loss dapat turun.
Output pembelajaran: mahasiswa belum harus menghasilkan sistem inspeksi ban yang akurat. Mereka harus mampu menjelaskan secara matematis bagaimana model belajar dari kesalahan.

13. Quiz Cepat

1. Apa fungsi loss?

Benar. Loss memberikan ukuran seberapa jauh prediksi model dari target.

2. Apa fungsi learning rate?

Benar. Learning rate mengontrol ukuran langkah saat parameter diperbarui.

3. Apa yang berubah selama training?

Benar. Parameter diperbarui menggunakan informasi gradient.

4. Apakah epoch lebih banyak selalu berarti model lebih bagus?

Benar. Performa perlu diamati pada training dan validasi; terlalu lama belajar dapat menimbulkan masalah seperti overfitting.
