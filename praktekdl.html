1️⃣ Teori & Praktik Tensor Teori Praktik

📖 Apa itu Tensor?

Tensor adalah struktur data multidimensi yang menjadi "jantung" dari PyTorch. Tensor mirip dengan numpy.ndarray, tetapi memiliki dua keunggulan utama:

  • 🚀 Dapat berjalan di GPU — komputasi jauh lebih cepat
  • 🧮 Mendukung autograd — perhitungan gradient otomatis untuk deep learning

Hierarki Dimensi Tensor

Dimensi Nama Contoh di Industri Ban
0DSkalarSuhu tungku: 150.0
1DVektorSpesifikasi 1 ban: [16, 205, 55, 32]
2DMatriksBatch 5 ban × 4 fitur
3DTensor 3DGambar RGB: (C, H, W) = (3, 224, 224)
4DTensor 4DBatch gambar: (N, C, H, W) = (32, 3, 224, 224)

2️⃣ Autograd - Gradient Otomatis Teori

📖 Apa itu Autograd?

Autograd adalah mesin diferensiasi otomatis PyTorch. Ia merekam semua operasi pada tensor yang memiliki requires_grad=True, membangun computational graph, lalu menghitung gradient saat .backward() dipanggil.

Alur Autograd:

  1. Tandai tensor: requires_grad=True
  2. Lakukan operasi (forward pass) — graph direkam
  3. Panggil .backward() — gradient dihitung
  4. Akses gradient via .grad
# Optimasi biaya produksi: f(x) = x² + 3x + 5
x = torch.tensor(2.0, requires_grad=True)

y = x**2 + 3*x + 5
print(f"x = {x.item()}, y = {y.item()}")

y.backward()
print(f"dy/dx = {x.grad.item()}")  # 2x + 3 = 7

x2 = torch.tensor(-1.5, requires_grad=True)
y2 = x2**2 + 3*x2 + 5
y2.backward()
print(f"x = {x2.item()}, dy/dx = {x2.grad.item()}")  # = 0 → minimum!
x = 2.0, y = 15.0 dy/dx = 7.0 x = -1.5, dy/dx = 0.0
💡 Insight: Saat gradient = 0, kita berada di titik minimum lokal. Inilah dasar dari gradient descent untuk training neural network!

3️⃣ Membangun MLP Teori

📖 Apa itu MLP?

MLP adalah neural network feedforward yang terdiri dari:

  • Input Layer — menerima fitur
  • Hidden Layer(s) — transformasi non-linear
  • Output Layer — menghasilkan prediksi

Rumus tiap layer: y = activation(W·x + b)

🎯 Studi Kasus MLP: Prediksi umur pakai ban berdasarkan 4 parameter produksi. 

from torch.utils.data import Dataset, DataLoader

torch.manual_seed(42)

def buat_dataset_ban(n_samples=2000):
    ketebalan = torch.rand(n_samples) * 5 + 5       # 5-10 mm
    tekanan = torch.rand(n_samples) * 10 + 28       # 28-38 psi
    suhu = torch.rand(n_samples) * 20 + 25          # 25-45 °C
    beban = torch.rand(n_samples) * 600 + 400       # 400-1000 kg
    
    X = torch.stack([ketebalan, tekanan, suhu, beban], dim=1)
    umur = (5.0*ketebalan + 0.1*tekanan - 0.5*suhu 
            - 0.01*beban + torch.randn(n_samples) * 2)
    umur = (umur - umur.min()) / (umur.max() - umur.min()) * 50 + 30
    return X, umur.unsqueeze(1)

X, y = buat_dataset_ban(2000)
print(f"Shape X: {X.shape}, Shape y: {y.shape}")
Shape X: torch.Size([2000, 4]), Shape y: torch.Size([2000, 1])
class MLPUmurBan(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(4, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 1)
        )
    
    def forward(self, x):
        return self.network(x)

model = MLPUmurBan()
total_params = sum(p.numel() for p in model.parameters())
print(f"Total parameter: {total_params}")

4️⃣ Training Loop Praktik

📖 Anatomi Training Loop

  1. Forward pass — model prediksi dari input
  2. Hitung loss — bandingkan prediksi dengan target
  3. Zero grad — reset gradient dari iterasi sebelumnya
  4. Backward pass — hitung gradient
  5. Update parameter — optimizer step
